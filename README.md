# Zone Builder

Editor desktop de zonas e spawns para servidores de Lineage II. Abra os mapas do cliente em 3D, desenhe áreas sobre o terreno e gere o XML para o servidor.

## Recursos

- Criação e edição de zonas, incluindo exclusões, faixa de altura e zonas de água.
- Distribuição de monstros em áreas de spawn, com prévia no mapa.
- Validação das zonas e exportação de XML com opção de copiar.
- Projetos `.zbproj`, desfazer e refazer, interface em português e inglês.
- Exploração do mapa com um personagem, gravidade e colisão.

Disponível para Windows 64 bits. Requer um cliente de Lineage II com a pasta `Maps`.
